Built to be trusted

Simple to use.
Serious underneath.

FLUX is a real transfer engine, not a pretty wrapper. Here is what it does today.

01

Any size, tiny memory

Files stream in small chunks, so a huge video never fills your RAM.

02

Picks up where it stopped

Connection drops? FLUX reconnects and resumes from what was already verified.

03

Folders stay folders

Send a whole project and it arrives with the same structure and names.

04

Nothing overwritten

Same name already there? You get “report (1).pdf”, never a silent replacement.

05

Pause, resume, cancel

Stop any time and keep your progress, or cancel and leave nothing behind.

06

Local-first

Files go straight from device to device. No account, no upload, no cloud copy.

Security

Discovery is not trust.

Seeing a device on your network never lets it send you anything.

PAIR

One-time codes

Pairing uses a short-lived, single-use code that is useless once it has been used.

PIN

Identity, not IP address

Every device has its own cryptographic identity, checked on every connection.

ASK

You decide

Unknown devices need your approval for each transfer, and you see the files first.
